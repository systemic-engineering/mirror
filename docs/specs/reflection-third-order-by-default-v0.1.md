The pipeline observes the world. In mirror's compiler-loop framing,

The Reflection observes the pipeline observing the world. This is
Foerster's altitude — the observer is inside the system observed. In

places:

  cybernetic primitive.

  that Reflection IS the meta-pipeline observing the pipeline. The

The recognition this tick lifts is that the second-order is not

Second-order signature (existing; this spec does not modify):


The signature is the same as first-order; the altitude is what
differs. The substrate-decl claim is that `observe` at @reflection
