## 2. The gap precisely

### 2.1 Mirror today — three-valued discipline at every altitude

The substrate has been performing three-valued honesty across every
verdict-carrying carrier since at least Q1:

```
verdict          = pass | partial(confidence) | failure(reason)
seam_review      = CLEAN | BOUNDED | DEFENSIVE
imperfect(a,e,l) = success(a) | failure(e) | partial(a,l)
transparency     = opaque | partial(opacity_map) | transparent
fracture_state   = closed | held(calendar_entry) | open
```

Each one is a discriminator across three structurally-distinct
states. None of them is binary; none of them is graded along a single
axis. Each carrier respects the substrate-pull-correct refusal-of-
collapse that the partial arm names: *we got a value AND we are
holding loss against it.*

The substrate-decl honesty is real. `partial` is not a degraded
success; it is its own carrier. `BOUNDED` is not a softened CLEAN;
it is its own review verdict. `held` is not a closed fracture; it
is the substrate's institutional record of indeterminacy.

But the discipline is 3-VALUED. The three states are mutually
exclusive. A verdict is exactly one of {pass, partial, failure} at
any given evaluation. The "partial" arm carries a loss-slot, but the
loss-slot has one carrier; it does not have three independent
components.

### 2.2 Smarandache 1995 — three-axis discipline per verdict

Florentin Smarandache's *Neutrosophy: Neutrosophic Probability, Set,
and Logic* (1995) introduces a structurally distinct shape. Each
proposition carries three components — Truth (T), Indeterminacy (I),
Falsity (F) — each ranging in [0, 1] (the classical neutrosophic
variant) or in the extended paraconsistent ranges (the paraconsistent
neutrosophic variant). The three components are INDEPENDENT — they
are not constrained to sum to 1, and any combination of (T, I, F)
values is admissible.

The structural consequences:

- A proposition can be simultaneously highly-true AND highly-false
  AND highly-indeterminate (the *paraconsistent* case; T + I + F > 1).
- A proposition can be simultaneously low-true AND low-false AND
  low-indeterminate (the *incomplete* case; T + I + F < 1).
- The classical sum-to-one case (T + I + F = 1) is one slice of a
  three-dimensional space, not the whole space.
- Indeterminacy is a primary carrier, not a derived quantity from
  T and F failing to sum.

This is not fuzzy logic with a different name. Zadeh's fuzzy sets
grade membership on a continuous interval but treat hesitation as
the leftover from T + F not filling the unit. Atanassov's
intuitionistic fuzzy sets (1986) split membership into degree-of-
belonging and degree-of-non-belonging with hesitation as the slack
between them — but hesitation is still derived. Smarandache's I is
its own dimension.

### 2.3 The second-order move

The gap mirror's candidate closes is the second-order move from:

```
3 verdicts (one-of-three states; discriminator-altitude discipline)
```

to:

```
3 axes per verdict (each verdict carries three independent
                    graded components; carrier-altitude discipline)
```

The first-order discipline (the discriminator) does not go away. The
candidate is structurally additive: a `verdict` of `pass` lifts to
a `neutrosophic_verdict` with the operational form `{ v: pass,
t: high, i: low, f: low }`; a `verdict` of `partial(confidence)`
lifts to `{ v: partial, t: confidence, i: high, f: low_or_high }`
depending on which paraconsistent slice the operator is naming; a
`verdict` of `failure(reason)` lifts to `{ v: failure, t: low,
i: low_to_high, f: high }`.

The lift is precise. The discriminator stays as the operational
shorthand the existing substrate-decl uses everywhere. The three-axis
carrier becomes the substrate's first-class form of *what the
discriminator was always implicitly attempting to express*.

The substrate already had the word — `imperfect.partial` carries
exactly one indeterminacy slot per arm; `verdict.partial` carries
exactly one confidence per arm; `transparency.partial` carries
exactly one opacity_map per arm. The substrate has been encoding
the indeterminacy axis as a *single* slot on the *single* partial
verdict. The candidate lifts that to the substrate-decl shape where
EVERY verdict (not just partial) carries T, I, F INDEPENDENTLY.

```

```

### 3.2 The `neutrosophic_verdict` typed record carrier

```
type neutrosophic_verdict = {
  v: verdict,
  t: ratio,
  i: ratio,
  f: ratio,
}
```

The substrate-architectural carrier for the three-axis discipline.
Each field's role:

- `v: verdict` — the existing three-valued discriminator, preserved

  intact; the substrate-pull-correct shorthand the existing carriers
  use everywhere keeps composing.
- `t: ratio` — the Truth axis. Smarandache's T component, typed
  as ratio, semantically the degree to which the verdict's
  underlying proposition holds.
- `i: ratio` — the Indeterminacy axis. Smarandache's I component,
  typed as ratio, semantically the degree to which the verdict's
  underlying proposition is structurally undetermined (not the
  same as "we don't know"; the substrate's record of irreducible
  indeterminacy).
- `f: ratio` — the Falsity axis. Smarandache's F component, typed
  as ratio, semantically the degree to which the verdict's
  underlying proposition does NOT hold.

Identity contract: byte-equality on the quadruple.

The three axes are INDEPENDENT by structural commitment. The
substrate-decl does NOT impose a `t + i + f = 1` constraint; the
bilateral predicate `axes_independent` (§3.6) discharges that
independence as a structural fact.

{
  case im of
    success(a)    -> { v: pass,    t: high, i: low,  f: low  }
