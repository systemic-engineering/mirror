### 2.3 The inter-peer resonance IS the Fabry-Perot lift from single-cavity to coupled-cavity

Fabry-Perot resonators, coupled through a shared medium, produce a
CAVITY-MODE STRUCTURE with a broader mode spectrum than either isolated
cavity (Siegman 1986 *Lasers*, ch. 12). This is standard laser physics.
Recognition #58 landed the SINGLE-cavity case at `@fate`. The N-cavity
coupled case is:

- 5 modes per cavity × N cavities = up to 5N modes ensemble.
- Under strong coupling (`|κ|` above threshold), the mode spectrum
  collapses toward the SHARED modes — the ensemble locks onto a small
  number of synchronized modes.
- Under weak coupling, the spectrum stays disjoint — each cavity lases
  on its own preferred mode.

**Substrate reading:** the coupling threshold IS Alex's "psychohistory.
basin" convergence threshold. Above threshold, the N peers converge to
one (or few) shared basin(s); below threshold, each peer stays in its
own preferred fate model.
