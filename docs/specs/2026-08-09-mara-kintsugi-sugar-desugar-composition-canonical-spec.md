## §3 Round-trip fidelity contract

### §3.1 Formal statement

For every shard `S` carrying a sugar-fracturable pattern (per §1), the following holds:

$$
\text{oid}(\text{resugar}(\text{sugar}(\text{source}(S)))) = \text{oid}(\text{source}(S))
$$

where:

- `source(S)` = the byte-content of shard `S` at source altitude.
- `sugar(x)` = the omission-morphism at source altitude (apply the four ratified fracture-detectors §1; omit each detected block).
- `resugar(y)` = the read-path projection at source altitude (via `@magic/reveal/expand`; reconstruct each omitted block from path-derived / pact-derived templates).
- `oid(x)` = the Blake3 content-address of `x` at `@mirror/store` altitude (per `@fractal/shard.materialize`).

The round-trip is **bit-exact** — not equivalent-up-to-normalization; not equal-modulo-whitespace; **byte-identical**. Compiler-emitted resugared bytes match hand-authored source bytes to the last byte.

### §3.2 Byte-verifiable pre/post

RED-first empirical test per §8:

```
oid_pre  = oid(source(S))                   # bytes before sugar
source'  = sugar(source(S))                 # apply omission-morphism
oid_post = oid(resugar(source'))            # resugar + rehash
assert oid_pre == oid_post                  # bit-parity gate
```

Any shard where `oid_pre ≠ oid_post` = substrate-decidable evidence the sugar rule needs refinement at that pattern-instance. Failing shard is quarantined; sugar rule does NOT apply until pattern is characterized + fracture-detector refined.

### §3.3 Store-side crystal invariance

Independent-and-equally-load-bearing:

$$
\text{oid}(\text{crystal}(\text{source}(S))) = \text{oid}(\text{crystal}(\text{sugar}(\text{source}(S))))
$$

where `crystal(x)` = the `@mirror/store` projection (the full-form graph representation; source-agnostic).

The crystal is INVARIANT under source-altitude sugar. Both dense (sugar-omitted) and readable (full-form) source project to bit-identical crystal at store altitude. **Store is canonical; source is a projection.**

### §3.4 Karen-citation preservation invariant (P5-specific)

For P5 path-namespace docblock omission (§1.4):

$$
\text{pact\_edge}(\text{crystal}(\text{source}(S))) = \text{pact\_edge}(\text{crystal}(\text{sugar}(\text{source}(S))))
$$

where `pact_edge(g)` = the graph edge `S -[declares_via]-> @epistemologic/pact/path_matches_namespace` at `@mirror/store` altitude.

The pact-citation edge MUST be preserved at store altitude even when source omits the docblock prose. This is the invariant that keeps grep-first-ancestry-check per Karen anti-theft working after sugar rule applies.
