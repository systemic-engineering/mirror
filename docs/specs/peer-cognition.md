## §3 — The standalone-use heuristic

### 3.1 Alex's principle

*"If it's composed standalone, root prism. If not, glass."*

A root prism `@X` is well-rooted iff there exists at least one shard
in the corpus that composes `@X` directly without parent context.
If no such shard exists, `@X` is a candidate for collapse into a glass
under its most frequent host.

This is the substrate's own well-foundedness rule: roots are
established by use, not by declaration. A namespace that nothing
composes standalone is not actually a root — it's syntactically
floating, structurally dependent.

### 3.2 The form-side: `@epistemologic/pact/standalone_use`

The declarative property. Form-side per
[[architecture-form-process-partition-at-family-root]]. Template per
`shards/epistemologic/pact/substrate_source_in_shards.mirror`.

```
in @glass

pact @epistemologic/pact/standalone_use {
  # The set of shards in `corpus` that compose `root` directly
  # without parent context. "Standalone" = the shard's `in <X>`
  # imports contain `<root>` itself, NOT a parent of `<root>`.
  # One entry per shard.
  standalone_compositions(corpus: ref, root: ref) -> [ref] { \ }

  # The most common host context for `root` across the corpus.
  # Read: for each shard that composes `root`, identify the
  # parent context (the most-deeply-nested `in <X>` such that
  # `<X>` is a prefix of `<root>` and `<X> != <root>`). Return
  # the most frequent parent.
  frequent_host(corpus: ref, root: ref) -> ref { \ }

  # The combined property: `standalone_use(corpus, root)` is
  # success iff `standalone_compositions(corpus, root)` is
  # non-empty.
  #
  # Verdict surface is transparency<p>:
  #   success              -- some shard composes `root` standalone;
  #                          `root` is well-rooted.
  #   failure(opacity_map) -- no shard composes `root` standalone;
  #                          the opacity_map carries the suggested
  #                          collapse morphism (mv root.mirror to
  #                          frequent_host/root.mirror; rewrite
  #                          `prism @root` to `glass @host/root`;
  #                          sweep importers).
  #   partial(opacity_map) -- standalone uses exist but are sparse
  #                          (below threshold); the opacity_map
  #                          carries warning data.
  standalone_use(corpus: ref, root: ref) -> transparency { \ }
}

out standalone_compositions
out frequent_host
out standalone_use
out @epistemologic/pact/standalone_use
```

Three actions. Each obligation-block discharges declaratively via
`splinter(ast)` (recognition #54). Forward-promised to T8.2.

**Self-witnessing.** The property's own shard lives at
`shards/epistemologic/pact/standalone_use.mirror` and declares with
`pact`. The test fixture composes it as `in @epistemologic/pact/standalone_use`
without parent context (the test shard's only `in` is the property
itself). This satisfies the property on its own first frame.

### 3.4 The sheaf-coherence measurement

The mathematical content of `post_collapse_coherence`. The substrate
vocabulary maps to the measurement as follows:

| Mathematical object | Substrate carrier | Existing home |
|---------------------|-------------------|---------------|
| Sheaf over the dependency-chain graph | (vocabulary kinship to eigensheaf, per `sheaf_laplacian.mirror`) | `@epistemologic/math/sheaf_laplacian` carriers (`restriction`, `operator`) |

| Per-edge curvature (Balanced Forman) | `curvature` | `shards/epistemologic/math/curvature.mirror` |

**The measurement procedure.**

Given a corpus `C` and a candidate collapse `R → H/R` (move root `R`
to sub-glass under host `H`):

1. Compute the dependency-chain graph `G_C` on the corpus before the
   collapse. Vertices: shards. Edges: `in <X>` imports.
2. Compute the post-collapse dependency-chain graph `G_C'` after the
   proposed move (rewrite `in @R` to `in @H/R`; relocate the shard).
3. Construct the sheaf restrictions from `G_C'` (one `restriction`
   per import-edge; weight = import multiplicity).
4. Assemble the sheaf-Laplacian operator via
   `sheaf_laplacian(restrictions) -> operator`.
5. Read the spectral gap via `lambda_zero(op) -> eigenvalue`.
6. Verdict:
   - **`λ₀ = 0` with multiplicity 1** (single connected component):
     collapse preserves coherence. The morphism is admissible.
   - **`λ₀ = 0` with multiplicity > 1** (multiple disconnected
     components): collapse fragments the dependency chain. **Do NOT
     collapse**; the Fiedler vector identifies which sub-glass
     boundary objects fragment.
   - **`λ₀ > 0` but small** (near-bottleneck): collapse leaves a
     thin connection; the Fiedler vector identifies the bottleneck
     edge. Per-edge curvature via `balanced_forman(op, edge)` tells
     WHICH edge is the bottleneck; the fracture may refuse or
     propose a different host.
