## §2 Lorenz 1963 — the butterfly effect as substrate-altitude sensitivity

### §2.1 The paper

Lorenz, E. N. (1963). *Deterministic Nonperiodic Flow.* Journal of
the Atmospheric Sciences 20(2):130-141.
<https://journals.ametsoc.org/view/journals/atsc/20/2/1520-0469_1963_020_0130_dnf_2_0_co_2.xml>
(Preprint mirror:
<https://cdanfort.w3.uvm.edu/research/lorenz-1963.pdf>). Cited
32,590+ times (per PhilPapers 2026). Founded chaos theory; the
"butterfly effect" name emerged from Lorenz's 1972 AAAS talk
("Predictability: Does the Flap of a Butterfly's Wings in Brazil
set off a Tornado in Texas?").

### §2.2 The equations

Lorenz derived a 3-variable dissipative system from Rayleigh-Bénard
convection:

```
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
```

with canonical parameters σ=10, ρ=28, β=8/3 producing the
strange attractor. **The load-bearing property is sensitive
dependence on initial conditions**: two trajectories starting from
initial states differing by ε > 0 diverge exponentially at rate λ
(the largest Lyapunov exponent, λ ≈ 0.9 for Lorenz's canonical
parameters), so ‖x(t) − x'(t)‖ ≈ ε·e^(λt).

### §2.3 Substrate lift

The substrate carries Lorenz's insight NOT as a physics simulator
but as a **discipline for how small perturbations propagate through

| Initial perturbation ε | One @mutation applied to the AST at t=0 |

## §3 Mutation coverage as butterfly-sensitivity

### §3.1 The metric

Let `M` be a mutation-operator set (arithmetic operator flips,
boundary shifts, conditional inversions — the classical Offutt-Jia
2010 taxonomy). For a target `T` and test suite `S`, define:

```
mutants(T, M) := { μ(T) : μ ∈ M applied to T }
kill(m, S)    := 1 if ∃ t ∈ S. verdict(t, m) ≠ verdict(t, T)
                 0 otherwise
coverage(T, S, M) := |{ m ∈ mutants(T, M) : kill(m, S) = 1 }|
                     ─────────────────────────────────────────────
                                 |mutants(T, M)|
```

This is the classical **mutation score** (Offutt-Untch 2001).
Bounded in [0, 1]; 1 = every mutant killed = maximal test-suite
sensitivity; 0 = every mutant survives = test suite blind.

### §3.2 The substrate delightfully-boring reading

**Coverage IS the butterfly-sensitivity of the test suite.** Rename
per Alex convention `<primitive>_of_<input-shape>`:

```
sensitivity_of_test_suite : (S: TestSuite, T: Target, M: MutationSet) → f64 ∈ [0, 1]
```

Signature is 1:1 with the classical mutation score; the RENAME
makes the geometric content visible. When the test suite is
sensitive (like a butterfly wing to a perturbation), coverage is
high. When it's blind, coverage is low. **The word `sensitivity`
comes from Lorenz's "sensitive dependence"; the fit is inevitable.**

### §3.3 Composition with pillar::forall

The substrate already carries the mechanism: `pillar::forall`
(Reed 2026-07-18 Arc 2, spec at `docs/specs/witnessed-property-
inference-fate-drives-both.md §7.3`) returns a `PropertyVerdict`
via `merge_with` fold. Given a mutant `m`:

```
sensitivity_of_test_suite(S, T, M) =
  |{ m ∈ M(T) : forall<Input, |x| verdict(S, m, x)> ≠ forall<Input, |x| verdict(S, T, x)> }|
  ──────────────────────────────────────────────────────────────────────────────────────────
                                    |M(T)|
```

**The RHS is computable without new machinery.** Every ingredient
lands in Reed's Arc 1-2 (see companion spec §9). What's added is
the OUTER LOOP over M(T) — the @butterfly's job (§4).

### §3.4 Connection to Lyapunov exponent

**FORWARD-PROMISED.** The Lyapunov exponent λ of a mutation
perturbation:

```
λ(m) := lim(t → ∞) (1/t) log ‖trace(m, t) − trace(T, t)‖
```

where `‖·‖` is Hamming distance on the `signature_beat` Merkle
chain up to tick t. The claim: `sensitivity_of_test_suite(S, T,
M) > 0` iff `∃ m ∈ M. λ(m) > 0`. Empirical measurement gate lands
in Arc 6 (see companion spec §9).

Prior-art connection: the sensitivity-compiler-testing framework
