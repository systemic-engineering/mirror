### §2.1 The task-corpus base graph G_task

**Definition 2.1.1 (task-corpus base graph).** Let `T = {t_1, t_2, ..., t_n}` be the set of all task-artifacts in the corpus at a given tick (an artifact IS a task iff it declares itself via `@task` substrate-decl per spec §2). ### §2.2 The task-corpus cellular sheaf F_task

**Definition 2.2.1 (task-corpus cellular sheaf).** The **task-corpus cellular sheaf** `F_task` over `G_task` assigns:

- **Vertex stalks** `F_task(v)` for each task-vertex `v ∈ V_task`: the front-matter + body vector space of the task per §2.3 — a finite-dimensional ℂ-vector space carrying the task's metadata (title, appetite, energy-budget, driver, status, hill-position) + the language-sheaf projection F_L over the task-body markdown text

- **Restriction maps** `F_task_{v ⊴ e} : F_task(v) → F_task(e)` — linear maps embedding a task-vertex-stalk into an incident edge-stalk

**Grounding.** Curry 2014 Def. 2.2.1 (cellular sheaf) + Hansen-Ghrist 2019 Def. 3.1 (sheaf Laplacian composability) + Rec #89 sheaf-cohomology unification (Mara 2026-08-13; sheaves as psychohistory carriers).

### §2.3 The task-vertex stalk decomposition

**Definition 2.3.1 (task-vertex stalk).** For each task-vertex `v ∈ V_task`, the vertex stalk decomposes as:

$$
F_{task}(v) = F_{meta}(v) \oplus F_{body}(v)
$$

where:

- **`F_meta(v)`** — the metadata vector space carrying the task's front-matter fields (title, appetite, energy-budget, driver, status, hill-position, migration-count, authored-by). Finite-dimensional; each field is a coordinate in a per-field enumerated space.
