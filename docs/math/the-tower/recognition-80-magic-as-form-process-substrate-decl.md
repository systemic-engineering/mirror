1. Every form/process instance in the substrate fits the
   surface/mechanism/contract three-part shape. If any form/process
   pair has no contract, #80 weakens.
2. The Splinter/Narcissus pole choice cleanly distinguishes honest-
   trick from deception across all observed instances.
3. The substrate's existing encapsulation mechanisms (OID, parametric,
   sheaf) realize the same `@magic` semantics at three altitudes.
4. Clarke's law admits a substrate-mathematical statement under #80
   (e.g., "a system with matter dim N and gauge visibility 5 appears
   as magic when N > some threshold relative to observer state").

Fails if:

- Some substrate form/process instance has no boundary contract.
- Honest-trick and deception cannot be distinguished mathematically
  within `@magic`.
- Clarke's law admits no rigorous substrate-mathematical statement.
- Some non-form/process substrate concept also fits `@magic`'s shape,
  meaning the name is too broad.
