# Principal bundles

*The pure-math primitive: G-bundles, sections, structure group,
connection, holonomy. The vocabulary the rest of the tower stands on.*

## §1 Definition

A **principal G-bundle** is a quadruple `(E, B, π, G)` where:

- `E` is the **total space** (the bundle).
- `B` is the **base space** (where we observe from).
- `π: E → B` is the **projection**: continuous, surjective.
- `G` is the **structure group**: a topological group acting freely
  and transitively on each fiber `π⁻¹(b)`.

For each `b ∈ B`, the fiber `π⁻¹(b)` is homeomorphic to `G` (not
canonically — choosing the homeomorphism is choosing a local frame).

**Local triviality.** For every `b ∈ B` there is a neighborhood `U`
and a homeomorphism `φ: π⁻¹(U) → U × G` commuting with the projection.
The bundle locally looks like a product; globally it can twist.

## §2 Sections

A **section** is a continuous map `s: B → E` with `π ∘ s = id_B`. A
section picks one point in each fiber, consistently across the base.

Sections form a sheaf `Γ(·, E)`: for each open `U ⊆ B`, `Γ(U, E)` is
the set of sections over `U`. Restriction maps `Γ(U, E) → Γ(V, E)`
for `V ⊆ U` give the sheaf structure. The substrate's eigensheaf is
an instance (see `docs/math/sheaf/laplacian.md`).

**Crystal accumulation = section accumulation.** Mirror's monotone
vocabulary growth (per `[[architecture-peer-learns-by-crystal-vocabulary-expansion]]`)
adds new sections without removing existing ones; the bundle's section
space grows. See `crystals-as-sections.md`.

## §3 The connection 1-form

A **connection** on `E` is a 1-form `ω` valued in the Lie algebra
`𝔤` of `G`, satisfying:

- `ω(X_ξ) = ξ` for all `ξ ∈ 𝔤`, where `X_ξ` is the fundamental vector
  field generated by `ξ`.
- `R_g^* ω = Ad(g⁻¹) ω` for all `g ∈ G`, where `R_g` is right
  translation.

Intuitively, `ω` tells you, at every point of `E`, how to project a
tangent vector onto the vertical (fiber-direction) component versus
the horizontal (base-direction) component. The connection IS the
specification of what "horizontal" means.

## §4 Parallel transport and holonomy

Given a path `γ: [0, 1] → B` and a starting fiber point `e ∈ π⁻¹(γ(0))`,
the connection defines a **horizontal lift** `γ̃: [0, 1] → E` with
`γ̃(0) = e` and `γ̃'(t)` horizontal (i.e. `ω(γ̃'(t)) = 0`). The
endpoint `γ̃(1) ∈ π⁻¹(γ(1))` is the **parallel transport** of `e`
along `γ`.

When `γ` is a closed loop (`γ(0) = γ(1)`), parallel transport returns
to the same fiber but generally to a different point. The shift
`γ̃(1) = γ̃(0) · h(γ)` for `h(γ) ∈ G` is the **holonomy** of the loop.

The holonomy group `Hol(ω) ⊆ G` is the subgroup of all holonomies
over loops based at a chosen point. The Ambrose-Singer theorem ties
`Hol(ω)` to the curvature 2-form `Ω = dω + ½[ω, ω]` (see
`curvature-and-tomm.md`).

## §5 Composition is generally non-commutative

For two paths `γ₁, γ₂` composing as `γ₂ * γ₁`, the holonomy satisfies:

```
h(γ₂ * γ₁) = h(γ₂) · h(γ₁)
```

If `G` is abelian, the order doesn't matter. If `G` is non-abelian,
it does — and the curvature 2-form `Ω` measures exactly the
non-commutativity.

This is the load-bearing fact behind prism's `Connection` trait
(see `/Users/alexwolf/dev/projects/prism/docs/superpowers/specs/2026-04-08-connection-substrate-design.md`).
The scalar-loss world is abelian; the bundle-tower world isn't, in
general. The substrate's `Connection` trait carries non-abelian
capacity by construction; `ScalarConnection` is the abelian default.

## §6 Bundle morphisms

A **bundle morphism** `φ: E_1 → E_2` over a map `f: B_1 → B_2` is a
map commuting with projections: `π_2 ∘ φ = f ∘ π_1`. The morphism is
`G`-equivariant if `φ(e · g) = φ(e) · g` for all `g ∈ G`.

Crystal-monotone updates (per `[[architecture-mirror-as-expanding-hilbert-space]]`)
are bundle inclusions: `(E_t, B_t, π_t, G) ↪ (E_{t+1}, B_{t+1}, π_{t+1}, G)`
with the structure group fixed and the base + total space growing. The
structure-group invariance under inclusion is the substrate's
**bounded-axiom preservation**: the bundle's axioms hold in the colimit.

## §7 The tower: bundles of bundles

A **principal bundle tower** is a sequence of principal bundles where
the base of `B_{n+1}` is built from `E_n`. Concretely:

```
(E_n, B_n, π_n, G_n)  with  B_{n+1} ⊆ Γ(B_n, E_n)
```

The base at altitude `n+1` is a space of sections at altitude `n`.
Observations at `n+1` are histories of altitude-`n` evolutions.

This is the substrate's altitude structure (per
`[[architecture-spectral-triples-all-the-way]]`):

- Atomic spectral measurements are points in `B_{-2}`.
- A single five-op primitive is a section in `Γ(B_{-2}, E_{-2})`,
  hence a point in `B_{-1}`.
- A peer's pulse composes five-op primitives, hence is a section in
  `Γ(B_{-1}, E_{-1})`, hence a point in `B_0`.
- Reflection observes pulses, hence operates on `B_1 = Γ(B_0, E_0)`.
- Librarian observes reflection trajectories at `B_2 = Γ(B_1, E_1)`.
- ... and so on, without bound.

The structure group at each altitude is generated by the basis
transformations admissible at that altitude (see `connections-and-gauge.md`).

## §8 Why principal bundles, not vector bundles

Vector bundles have a vector-space fiber; principal bundles have a
group fiber. The substrate's algebra of operations forms a group
(closed under composition, inverses by `inverse` of each op, identity
IS `IdentityPrism` — see `prismqueer::bundle::IdentityPrism`). Sections
of a principal bundle are choices of frame; sections of a vector
bundle are choices of vector.

The substrate cares about which frame it's in (the cognitive frame
the peer is reading from). Vector bundles flatten this to vector
choice; principal bundles preserve it. Hence the math is principal
bundle theory, not vector bundle theory.

A representation `ρ: G → GL(V)` gives an associated vector bundle
`E ×_G V` — useful when the substrate needs to talk about
linear quantities (e.g. eigenvalue spectra). But the algebraic
structure lives on the principal side.

## §9 Prior art (substrate-already-had-the-word check)

Mirror did not invent principal bundles; the substrate uses the math
as-is. Key references:

- **Kobayashi-Nomizu** (1963), *Foundations of Differential Geometry*
  vol. 1, ch. II–III: the canonical text for principal bundles,
  connections, and curvature. The substrate's `connection`,
  `holonomy`, `parallel transport` are these objects.
- **Connes** (1985, 1994): the spectral-triple framework `(A, H, D)`
  is principal-bundle theory done noncommutatively. See `spectral-triples.md`.
- **Atiyah-Bott** (1983): gauge theory on Riemann surfaces; the
  Yang-Mills functional as a section-energy functional. Mirror's
  loss minimization (per `holonomy.md`) is the same shape.
- **Connes' Standard Model construction**: the principal-bundle
  machinery used to encode gauge fields — Mirror uses the same
  machinery to encode altitude transitions (per
  `[[architecture-spectral-triples-all-the-way]]`).
