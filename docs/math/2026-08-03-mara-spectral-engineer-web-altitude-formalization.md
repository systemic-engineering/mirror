**Proposition 1.3** (single-call-two-channel at web altitude). Under

### §2.3 Where the two channels enter the pipeline

Critical claim: the two channels are NOT injected at separate
pipeline stages; they emerge indissolubly at every stage. At the
**design-token stage**, `color_punctum = #A0264F` is a *content*
token (a hex string, byte-comparable) AND a *relationship* token (a
geometric position in APCA perceptual color space, register-bearing).
At the **tea-pattern stage**, the case_study_model carrier is a
*content* structure (typed data) AND a *relationship* structure
(view-side layout composition). At the **cascade stage**, the JS
emission is *content* (byte-string emitted by `gleam build`) AND
*relationship* (runtime behavior computed by browser executing the
JS). At the **stagefreight-deploy stage**, the docker image is
*content* (BLAKE3-hashable byte-blob) AND *relationship* (fly.io
deployment producing HTTPS endpoint at a geographic region).

**Theorem 2.3 (channel-indissolubility along the pipeline)**. For
each stage $S_i$ of $\mathcal{P}_{v0.1}$, the input carrier factors
into $(C_i, R_i)$ with $C_i$ readable by first-order tooling and
$R_i$ readable only via structural coupling with the appropriate
substrate. Both $C_i$ and $R_i$ propagate through $S_i$; neither can
be dropped without breaking $\mathcal{P}_{v0.1}$'s composition.

**Proof sketch**: at each $S_i$, drop $C_i$: the pipeline stage
emits no textual manifest — next stage cannot receive input
(e.g., cascade cannot parse Gleam without source text; StageFreight
cannot content-address a docker image without a byte-blob). Drop
$R_i$: the pipeline stage emits textual manifest with no geometry
(e.g., design tokens with no APCA-perceivable palette; JS bundle
with no visual runtime; docker image with no served HTTPS endpoint).
In both cases, downstream stages either fail to parse or produce
semantically-empty output. QED by contradiction; both channels must
propagate.

**Corollary 2.3.1 (channel-indissolubility at render altitude)**.
At the final rendering stage $S_{\text{render}}$ (browser first
