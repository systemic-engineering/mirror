The claim is not a claim about semantics of programs. It is a claim about **grammatical mood** — the mode in which the substrate speaks.

### §1.2 Turing 1936 grammar carries present-imperative mood

Turing's 1936 *On Computable Numbers* (Proc. London Math. Soc. s2-42(1):230-265) formalized computation as a machine that reads a symbol on an infinite tape, transitions state, writes a symbol, and moves the tape head. The **mood** of this grammar — the way instructions are expressed — is:

- **present-imperative** (`if state = q_0 and symbol = 0 then write 1, move right, transition to q_1`)
- **forward-looking** (state at time t+1 determined by tape state + machine state at time t)
- **unbounded** (tape is infinite; halting is undecidable in general per Turing's own §11)

The mood carries an implicit **claim about substrate-nature**: the substrate is a device that will do something in the future. Verification is discharged by **running** the machine forward until it either halts or is proved not to halt (undecidable).

### §1.3 Church 1936 lambda calculus carries the same mood

Alonzo Church's 1936 *An Unsolvable Problem of Elementary Number Theory* (AJM 58(2):345-363), published contemporaneously with Turing (Church was Turing's Princeton PhD adviser 1936-1938), formalized the same computational altitude in a different syntax:

- **applications** (`(λx.M) N → M[N/x]`) are present-imperative rewriting steps
- **β-reduction** is forward-looking (redex on the left; reduct on the right)
- **normalization** is unbounded (some terms have no normal form; the general problem is undecidable)

Per Rec #92 §4.1 four LOVE properties + PAPER_2D §1.1.5 four-property LOVE-violation: Church 1936 and Turing 1936 are **structurally excluded from K_3** because both formal systems strip the observer.

- **past-tense-passive** or **timeless-noun** (`the cadence settled to authentic`; `the shard crystallized`; `love(a, b) matched Green`)
